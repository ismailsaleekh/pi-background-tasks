# Issue 13: Background tasks break pi if .claude is elsewhere than home
Author: rafaljanicki (NONE)
State: open; Created: 2026-09-04T19:07:40Z; Updated: 2026-09-04T19:07:40Z
URL: https://github.com/ismailsaleekh/pi-background-tasks/issues/13

The plugin contains that in its code:

```
export function loadClaudeAttributionAccount(
    configPath = join(homedir(), '.claude.json'),   // hard-coded, no env override
  )
```

However, if the `.claude.json` file is stored in an another place, it breaks Pi with error message: `Error: Anthropic attribution config /home/node/.claude.json could not be read: ENOENT: no such file or directory, open '/home/node/.claude.json'`

That option should be configurable
