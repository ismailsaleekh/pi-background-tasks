## Summary
Fixes #14.

Recover silently when a resumed/reloaded Anthropic session's projected history or model/system/tools/thinking profile no longer matches the last successful request. Instead of throwing permanently before transport, start a deterministic non-inheriting signature epoch and re-project messages before sending: visible prior thinking becomes text and stale signed/redacted blocks are not replayed. Clear the previous response ID and persist the new epoch on success so subsequent turns chain normally.

Simply clearing `previous` would leave prefix-bound signatures in the request. This change coordinates recovery with projection while retaining middleware tamper checks, concurrency guards, retention/compaction transitions, and strict transport validation. Existing lineage records remain readable; no setting or per-turn warning is added.
