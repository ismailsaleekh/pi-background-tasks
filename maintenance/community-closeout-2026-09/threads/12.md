## Summary

- add exact regression coverage for replaying a `cpa/openai-responses` tool call through the package-owned Anthropic beta transport
- cover the observed composite ID shape `call_x|fc_y` and assert the normalized `tool_use.id` remains linked to its `tool_result.tool_use_id`
- preserve an already-valid tool ID and an image block in the same request

The production normalization shipped in 2.5.0; this PR pins the real cross-provider failure mode so it cannot regress silently.

## Regression evidence

Against the 2.4.2 implementation, the fixture forwards `call_x|fc_y` unchanged and fails the Anthropic ID constraint. Against current main, the ID is normalized to `^[a-zA-Z0-9_-]{1,64}$` and the result linkage is preserved.
