# Acceptance matrix

All rows start **PENDING_IMPLEMENTATION**. Evidence from contributor branches is not evidence of integration into our branch. Never mark a request closed merely by changing documentation, suppressing its error, widening peer ranges, adding an unused primitive, or noting that unit tests pass.

Before implementing a row, record a concrete behavioral decision and red reproduction, including the supported configurations/platforms. Defaults remain compatible; invasive process survival and built-in-tool takeover are opt-in. If a compatible implementation cannot satisfy the actual request, record the precise policy decision requiring operator approval rather than quietly reducing scope.
